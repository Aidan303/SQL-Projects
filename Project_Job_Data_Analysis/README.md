 # Introduction
 Dive into the data job market! Focusing on Data Analyst roles, this project explores top-paying jobs, in-demand skills, and where high demand meets high salary in data analytics.

 SQL queries? Check them out more here: [Analysis_SQL folder](/Project_Job_Data_Analysis/Analysis_sql/)

 # Background
 This projet was born out of my curiosity into the skills and job opportunities in my future field.
 I wanted to see what skills would be useful to me
 and how I could use certain skills to get job perks I want. Things like higher salaries, optimal work locations, the ability to work remote etc.
 # Tools I used
 This project was created using PostgreSQL to analyze a CSV based dataset pulled from an online data aggregation. The data was scraped from job posting sites such as LinkedIn, Indeed, etc.
 # The Analysis
1. The goal of this project was to find insights to help me in my job search. Focusing mainly on Data Analyst jobs I found that the most demanded skills needed for these types of jobs are SQL, Python, and Excel. 

2. Additionally I found that the top paying Data Analyst jobs had high demand for specialized skills. The ability to use speciailzed Data Pipeline software was especially highly demanded.

3. Finally I found the most optimal skills to learn that are both high in demand for Data Analyst jobs and lead to higher salaried jobs.
 # What I learned
This project taught me not only how to approach the job market in my future but also what employers are looking for from candidates. Going forward I'm going to look to focus on learning skills that I can use to achieve my personal goals in the job market.
 # Conclusion
In looking through the job data set I was able to make multiple insights that are incredibly valuable to me. I was able to see what to focus my learning on to get a job following my college graduation. Additionally, I was able to practically apply skills that I will use on a day to day basis in my future job. I see this project as a great basic introduction into the use of SQL and how to utilize it.
